# M1 — Voice-note feedback

Goal: the gurukula can give feedback from any page and the admin can play it back. (Nightly transcription comes in M9.)

---

### M1-01 Storage helper
**Lane** Platform · **Depends** M0-06 · **Spec** [02-schema § Files](../docs/architecture/02-schema.md#files), D16

- `src/server/storage.ts`: `createUploadUrl(bucket, path)`, `createDownloadUrl(bucket, path, ttl = 300)`, `removeObject`.
- Client `uploadFile(signedUrl, file)` + `compressImage(file)` (≈200 KB, long edge 1600 px); PDF size cap of 5 MB.

**Accept**
- [ ] Download URLs expire after the TTL (test)
- [ ] A 4 MB JPEG uploads at ≤ 250 KB

### M1-02 Record feedback
**Lane** Feature A · **Depends** M1-01, M0-07 · **Spec** [04-ui-spec § RecordButton](../docs/architecture/04-ui-spec.md#shared-components)

- Floating mic on every page; MediaRecorder (webm/opus); 3-minute cap; re-record; send → upload + `feedback` row with `page_context` (route + child id if on a profile).
- Handle a denied microphone permission gracefully.

**Accept**
- [ ] Works on Android Chrome (manual check, recorded in the PR) and desktop Chrome
- [ ] The row stores author, duration and page context

### M1-03 Feedback list
**Lane** Feature A · **Depends** M1-02 · **Spec** [04-ui-spec § Feedback](../docs/architecture/04-ui-spec.md#feedback-feedback)

- Admin: all feedback, player, transcript, status, triage note. Others: their own.

**Accept**
- [ ] A non-admin can't see others' feedback (server test)
