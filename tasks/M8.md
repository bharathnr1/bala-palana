# M8 — Reports, alumni and pilot

Goal: all reports with CSV and print; alumni; a proven restore; a user guide; pilot sign-off.

---

### M8-01 Child journey report (printable)
**Lane** Feature A · **Depends** M2-03, M4-03, M6-04

- `/reports/child/[id]`: year-by-year summary (enrolments, assessments trend, achievements, roles, duty counts, open items); an A4 print stylesheet.

**Accept**
- [ ] Prints to 1–3 pages for a demo child with 3 years of data; restricted sections are omitted for roles without `restricted.read`

### M8-02 Remaining reports
**Lane** Feature B · **Depends** M3-02, M5-01, M6-04 · **Spec** [design §7](../docs/design-doc.md#7-reports)

- `v_yearly_trends`; pages for Trends, Achievements & participation, Admissions funnel; Reports index.

**Accept**
- [ ] Every report has filters, a chart, a table, and Export CSV / Print

### M8-03 Exports
**Lane** Platform · **Depends** M8-02

- A generic CSV exporter for report views (refactor M4-04 onto it); an admin "Export all data" (a zip of CSVs per table, restricted data included only for admin).

**Accept**
- [ ] The full export opens in a spreadsheet with correct Indian-rupee and date formats

### M8-04 Alumni
**Lane** Feature A · **Depends** M2-01

- A "Mark as alumna / withdrawn" action (left_on, reason); the `/alumni` list; own contact details; log an alumni interaction (entry category).

**Accept**
- [ ] Alumnae are excluded from duty pickers and the default Children filter, but their Journey stays intact

### M8-05 Audit viewer and storage usage
**Lane** Platform · **Depends** M0-09

- Settings → Audit (filter by table, user, date; before/after diff); Settings → Storage (usage bars against free limits).

**Accept**
- [ ] Only admin can open them (server test)

### M8-06 Pilot readiness
**Lane** QA · **Depends** all M8 tasks

- Accessibility pass (axe in Playwright on key screens); Lighthouse mobile ≥ 85 performance on Home and Profile; security checklist (env guards, RLS lock-down, no public URLs, permission tests); restore drill repeated on the latest backup.

**Accept**
- [ ] No serious or critical axe violations; Lighthouse targets met; checklist attached to the PR

### M8-07 User guide
**Lane** QA · **Depends** M8-06

- `docs/user-guide.md`: install the app, sign in, record an observation, follow-ups, duty board, academics, admissions, reports, feedback. Short, task-based, with screenshots from demo data only.

**Accept**
- [ ] A non-technical reader can complete "record an observation" from the guide alone (reviewer checks)
