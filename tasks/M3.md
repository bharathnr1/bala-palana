# M3 — Duties and responsibilities

Goal: cycles are auto-generated and editable; there's a duty board; "who was on duty" is answered in ≤ 10 s.

---

### M3-01 Cycle engine
**Lane** Platform · **Depends** M0-04 · **Spec** D8, [04-ui-spec § Duties](../docs/architecture/04-ui-spec.md#duties-duties)

- `src/lib/cycles.ts`: generate cycles from `cycle_rule` (`half_month`: 1–15 and 16–end; designed for future rules such as `every_n_days`); idempotent `ensureCycles(from, to)`.
- Actions: edit dates, split, merge, pause, skip, set status.
- The duty board calls `ensureCycles` on load for the current and next 2 months, so no scheduled job is needed.

**Accept**
- [ ] Unit tests: Feb 2027 (28 days), Feb 2028 (29), April (30), May (31)
- [ ] Edits that would overlap are rejected with a readable error

### M3-02 Duty queries
**Lane** Platform · **Depends** M3-01 · **Spec** [02-schema § Views](../docs/architecture/02-schema.md#views-and-functions)

- `fn_on_duty`, `v_duty_counts`; add duty stints to `v_child_timeline`.

**Accept**
- [ ] A mid-cycle swap: A until the 7th, B from the 8th; `fn_on_duty` on the 7th returns A and on the 8th returns B

### M3-03 Duty board
**Lane** Feature A · **Depends** M3-01, M0-08 · **Spec** [04-ui-spec § Duties](../docs/architecture/04-ui-spec.md#duties-duties)

- Cycle switcher; duty cards with teams; add team; add, move or remove children; set lead; set member dates; copy last cycle; mobile tap menu, desktop drag and drop.

**Accept**
- [ ] Copy last cycle reproduces teams and leads, and skips children no longer `student`
- [ ] A child can be in two teams in the same cycle
- [ ] A teacher sees a read-only board

### M3-04 Who was on duty
**Lane** Feature B · **Depends** M3-02 · **Spec** [04-ui-spec § Duties](../docs/architecture/04-ui-spec.md#duties-duties)

- `/duties/lookup`: duty + date → members, leads, links.

**Accept**
- [ ] Answer shown within 2 taps after the date is picked; DB query < 100 ms on demo data

### M3-05 Responsibilities and duties tab
**Lane** Feature B · **Depends** M3-02, M2-01

- Profile tab: roles held (responsibility entries, current vs past), duty history by cycle, counts per duty for a chosen period.

**Accept**
- [ ] Counts match `v_duty_counts` for the selected academic year
